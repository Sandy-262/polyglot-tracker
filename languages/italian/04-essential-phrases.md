# Lesson 4: Essential Phrases

**Goal:** Build a survival kit of phrases that cover 90% of short real-world interactions.

## Politeness basics

| Italian | Pronunciation guide | English |
|---|---|---|
| per favore | pehr fah-VOH-reh | please |
| grazie | GRAH-tsyeh | thank you |
| grazie mille | GRAH-tsyeh MEEL-leh | thanks a lot |
| prego | PREH-goh | you're welcome / go ahead |
| scusa / scusi | SKOO-zah / SKOO-zee | sorry / excuse me (informal / formal) |
| mi dispiace | mee dees-PYAH-cheh | I'm sorry (sympathy) |
| permesso | pehr-MEHS-soh | excuse me (to pass by) |

## Yes, no, and basics

| Italian | Pronunciation guide | English |
|---|---|---|
| sì | see | yes |
| no | noh | no |
| forse | FOHR-seh | maybe |
| non lo so | nohn loh soh | I don't know |
| non capisco | nohn kah-PEES-koh | I don't understand |
| non parlo bene l'italiano | nohn PAHR-loh BEH-neh lee-tah-LYAH-noh | I don't speak Italian well |
| parla inglese? | PAHR-lah een-GLEH-zeh | do you speak English? |
| può ripetere? | pwoh ree-PEH-teh-reh | can you repeat that? |
| più lentamente, per favore | pyoo lehn-tah-MEHN-teh | more slowly, please |

## Practical questions

| Italian | Pronunciation guide | English |
|---|---|---|
| Dov'è il bagno? | doh-VEH eel BAH-nyoh | Where is the bathroom? |
| Quanto costa? | KWAHN-toh KOHS-tah | How much does it cost? |
| Posso avere...? | POHS-soh ah-VEH-reh | Can I have...? |
| Dov'è...? | doh-VEH | Where is...? |
| C'è...? | cheh | Is there...? |
| Aiuto! | ah-YOO-toh | Help! |

## Question words

| Italian | Pronunciation guide | English |
|---|---|---|
| chi | kee | who |
| cosa / che cosa | KOH-zah | what |
| quando | KWAHN-doh | when |
| dove | DOH-veh | where |
| perché | pehr-KEH | why / because (same word!) |
| come | KOH-meh | how |
| quanto/a | KWAHN-toh/tah | how much |

## Practice

1. Say all 7 question words out loud with an example question for each (e.g. "Dove? → Dov'è il bagno?").
2. Practice the "emergency trio": "Non capisco", "Parla inglese?", "Più lentamente, per favore" — say them back to back as if you just got lost in conversation.
3. Role-play: ask "Quanto costa?" and "Posso avere...?" for 3 items you'd actually buy on a trip.
4. Record yourself saying "perché" — it does double duty for both "why" and "because", make sure you can hear the difference in context.
