# Lesson 4: Essential Phrases

**Goal:** Handle everyday survival situations — politeness, confusion, and basic questions.

## Politeness & survival basics

| Malayalam script | Transliteration | English |
|---|---|---|
| ദയവായി | dayavāyi | please |
| നന്ദി | nandi | thank you |
| വളരെ നന്ദി | vaḷare nandi | thank you very much |
| ക്ഷമിക്കണം | kṣamikkaṇam | sorry / excuse me |
| സാരമില്ല | sāramilla | no problem / it's okay |
| അതെ | athe | yes |
| ഇല്ല | illa | no |
| ശരി | śari | okay / alright |
| എനിക്ക് മനസ്സിലായില്ല | enikku manassilāyilla | I don't understand |
| എനിക്ക് മനസ്സിലായി | enikku manassilāyi | I understand |
| നിങ്ങൾക്ക് ഇംഗ്ലീഷ് അറിയാമോ? | niṅṅaḷkku iṅgḷīṣ aṟiyāmō? | do you speak English? |
| പതുക്കെ പറയാമോ? | pathukke paṟayāmō? | can you speak slowly? |
| ഒന്നുകൂടി പറയാമോ? | onnukūṭi paṟayāmō? | can you repeat that? |
| ടോയ്‌ലറ്റ് എവിടെയാണ്? | ṭoyleṭṭŭ eviṭeyāṇŭ? | where is the bathroom? |
| ഇതിന് എന്ത് വില? | ithinŭ enthŭ vila? | how much is this? |
| സഹായിക്കാമോ? | sahāyikkāmō? | can you help me? |

## Mini-dialogue: asking for help

> **A:** ക്ഷമിക്കണം, സഹായിക്കാമോ?
> *(kṣamikkaṇam, sahāyikkāmō?)* — Excuse me, can you help me?
>
> **B:** തീർച്ചയായും, എന്താണ് വേണ്ടത്?
> *(thīrchayāyum, enthāṇŭ vēṇṭathŭ?)* — Of course, what do you need?
>
> **A:** ടോയ്‌ലറ്റ് എവിടെയാണ്?
> *(ṭoyleṭṭŭ eviṭeyāṇŭ?)* — Where is the bathroom?
>
> **B:** അവിടെ, വലതുവശത്ത്.
> *(aviṭe, valathuvaśaththŭ)* — Over there, on the right.
>
> **A:** നന്ദി!
> *(nandi!)* — Thank you!

## Practice

1. Say all 8 question words out loud, then write a simple question with each.
2. Practice the mini-dialogue with a friend or by recording both parts yourself.
3. Ask "ithinŭ enthŭ vila?" about 5 random objects around you.
4. Say "enikku manassilāyilla" and "pathukke paṟayāmō?" back-to-back — these two phrases alone will get you far as a beginner.
