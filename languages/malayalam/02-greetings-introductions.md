# Lesson 2: Greetings & Introductions

**Goal:** Greet someone, introduce yourself, and ask basic "how are you" questions — respectfully.

## A note on respect

Kerala culture places strong weight on respectful address, especially toward elders and strangers. Malayalam has two "you" forms:
- **നിങ്ങൾ (niṅṅaḷ)** — respectful/plural "you" — default for strangers, elders, and formal settings
- **നീ (nī)** — intimate "you" — only for close friends, children, or people clearly younger than you

When in doubt, use **niṅṅaḷ**. Using **nī** with the wrong person can sound rude.

## Core greetings

| Malayalam script | Transliteration | English |
|---|---|---|
| നമസ്കാരം | namaskāram | hello / goodbye (formal, respectful, used anytime) |
| ഹായ് | hāyŭ | hi (casual, borrowed from English) |
| സുഖമാണോ? | sukhamāṇō? | how are you? (lit. "is it well?") |
| സുഖമാണ് | sukhamāṇŭ | I am fine |
| സുഖമില്ല | sukhamilla | I am not well |
| നന്നായിരിക്കുന്നു | nannāyirikkunnu | I am doing well (more detailed) |
| എന്റെ പേര് ... | ente pēru ... | my name is ... |
| നിങ്ങളുടെ പേരെന്താണ്? | niṅṅaḷuṭe pēr enthāṇŭ? | what is your name? |
| സന്തോഷം | santhōṣham | nice to meet you (lit. "happiness") |
| കാണാം | kāṇām | see you (later) |
| വീണ്ടും കാണാം | vīṇṭum kāṇām | see you again |
| ശുഭരാത്രി | śubharāthri | good night |
| ഗുഡ് മോണിംഗ് | guḍ mōṇiṅg | good morning (commonly borrowed from English) |

## Example dialogue

> **A:** നമസ്കാരം! സുഖമാണോ?
> *(namaskāram! sukhamāṇō?)* — Hello! How are you?
>
> **B:** സുഖമാണ്, നന്ദി. നിങ്ങൾക്ക് സുഖമാണോ?
> *(sukhamāṇŭ, nandi. niṅṅaḷkku sukhamāṇō?)* — I'm fine, thanks. Are you well?
>
> **A:** സുഖമാണ്. എന്റെ പേര് അരുൺ.
> *(sukhamāṇŭ. ente pēru aruṇ.)* — I'm well. My name is Arun.
>
> **B:** സന്തോഷം അരുൺ. ഞാൻ പ്രിയ.
> *(santhōṣham aruṇ. ñān priya.)* — Nice to meet you, Arun. I'm Priya.
>
> **A:** വീണ്ടും കാണാം!
> *(vīṇṭum kāṇām!)* — See you again!

## Useful extras

| Malayalam script | Transliteration | English |
|---|---|---|
| ഞാൻ | ñān | I |
| നിങ്ങൾ | niṅṅaḷ | you (respectful) |
| അവൻ / അവൾ | avan / avaḷ | he / she |
| സുഖം തന്നെ | sukham thanne | all's well |
| എവിടെ നിന്നാണ്? | eviṭe ninnāṇŭ? | where are you from? |
| ഞാൻ ... നിന്നാണ് | ñān ... ninnāṇŭ | I am from ... |

## Practice

1. Say the full dialogue out loud, both parts, 3 times.
2. Introduce yourself using **niṅṅaḷ**-level respect, then again casually with **nī** phrasing, and notice the difference.
3. Record yourself asking "niṅṅaḷuṭe pēr enthāṇŭ?" and compare to a native clip.
4. Practice answering "sukhamāṇō?" with both the positive and the "not well" response.
