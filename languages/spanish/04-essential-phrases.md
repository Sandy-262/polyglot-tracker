# Lesson 4: Essential Phrases

**Goal:** Survive any situation with a core set of polite, practical phrases and question words.

## Politeness basics

| Spanish | Pronunciation guide | English |
|---|---|---|
| Por favor | pohr fah-VOHR | Please |
| Gracias | GRAH-syahs | Thank you |
| Muchas gracias | MOO-chahs GRAH-syahs | Thank you very much |
| De nada | deh NAH-dah | You're welcome |
| Lo siento | loh SYEHN-toh | I'm sorry |
| Perdón / Disculpe | pehr-DOHN / dees-KOOL-peh | Excuse me / Pardon |
| Sí / No | see / noh | Yes / No |

## Getting by

| Spanish | Pronunciation guide | English |
|---|---|---|
| No entiendo | noh ehn-TYEHN-doh | I don't understand |
| No hablo español muy bien | noh AH-bloh ehs-pah-NYOHL mwee byehn | I don't speak Spanish very well |
| ¿Habla inglés? | AH-blah een-GLEHS | Do you speak English? |
| ¿Puede repetir, por favor? | PWEH-deh reh-peh-TEER | Can you repeat, please? |
| ¿Puede hablar más despacio? | ... ahs DEHS-pah-syoh | Can you speak more slowly? |
| ¿Dónde está el baño? | DOHN-deh ehs-TAH ehl BAH-nyoh | Where is the bathroom? |
| ¿Cuánto cuesta esto? | KWAHN-toh KWEHS-tah EHS-toh | How much does this cost? |
| ¿Me puede ayudar? | meh PWEH-deh ah-yoo-DAHR | Can you help me? |
| Necesito ayuda | neh-seh-SEE-toh ah-YOO-dah | I need help |

## Question words

| Spanish | Pronunciation guide | English |
|---|---|---|
| ¿Qué? | keh | What? |
| ¿Quién? | kyehn | Who? |
| ¿Cuándo? | KWAHN-doh | When? |
| ¿Dónde? | DOHN-deh | Where? |
| ¿Por qué? | pohr keh | Why? |
| ¿Cómo? | KOH-moh | How? |
| ¿Cuál? | kwahl | Which? |
| ¿Cuánto/a? | KWAHN-toh/tah | How much? |

Note: Spanish uses an upside-down question mark (¿) at the *start* of a question as well as the normal one at the end — this is standard in all Spanish writing.

## Practice

1. Say all 8 "Getting by" phrases out loud without looking, then check yourself.
2. Make up 3 questions using different question words (qué, dónde, cuándo).
3. Practice the sequence: ask "¿Habla inglés?", then say "No entiendo" if they say no, then ask them to repeat slowly.
4. Memorize "¿Cuánto cuesta esto?" and use it mentally every time you look at a price tag this week.
