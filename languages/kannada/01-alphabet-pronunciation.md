# Lesson 1: Alphabet & Pronunciation

**Goal:** Recognize the Kannada script's building blocks and learn the romanization convention used throughout this library.

## Before you start: how Kannada is different

Kannada (ಕನ್ನಡ) is a **Dravidian** language spoken mainly in Karnataka, India — it is *not* related to Italian, Spanish, or French. Two big adjustments coming from those languages:

- **Its own script.** Kannada is written in the Kannada script, an **abugida**: each consonant letter carries an inherent vowel (usually "a") unless a vowel marker changes it. It is not an alphabet like the Latin script.
- **Word order is SOV** (Subject–Object–Verb), not SVO like English/Romance languages. See Lesson 7 for details — don't worry about it yet, just notice it in example sentences from Lesson 2 onward.

## Romanization convention used in this library

Kannada has sounds English doesn't mark clearly, so every lesson here uses this consistent romanization:

- Long vowels are written **doubled**: `a` vs `aa`, `i` vs `ii`, `u` vs `uu`.
- Retroflex consonants (tongue curls back, tip touches roof of mouth) are marked with a **capital letter**: `T`, `D`, `N`, `L` — as opposed to dental `t`, `d`, `n`, `l` (tongue touches teeth).
- `ṇ`-type nasals are simplified to plain `n`/`N` for readability; don't worry about the IPA details.
- A middle dot separates syllables only when it helps pronunciation, e.g. `na·maskaara`.

This is a simplified teaching romanization, not a strict academic transliteration standard (like ISO 15919) — good enough to be understood and to read your own notes back.

## Consonants (ವ್ಯಂಜನಗಳು — vyanjanagalu) — a starter set

| Kannada | Romanized | Note |
|---|---|---|
| ಕ | ka | like English "k" |
| ಗ | ga | like English "g" |
| ಚ | cha | like "ch" in "chair" |
| ಜ | ja | like "j" in "jam" |
| ತ | ta | **dental** t, tongue on teeth |
| ಟ | Ta | **retroflex** T, tongue curls back |
| ದ | da | dental d |
| ಡ | Da | retroflex D |
| ನ | na | dental n |
| ಣ | Na | retroflex n (less common, mostly mid-word) |
| ಪ | pa | like English "p" |
| ಬ | ba | like English "b" |
| ಮ | ma | like English "m" |
| ಲ | la | like English "l" |
| ಳ | La | retroflex l — tongue curls back further than English "l" |
| ರ | ra | lightly rolled/tapped r |

The dental vs. retroflex distinction (`t`/`T`, `d`/`D`, `n`/`N`, `l`/`L`) is the single biggest pronunciation trap for English speakers — the two sounds can change a word's meaning entirely.

## Listen & Practice

- Paste any word above into [Google Translate](https://translate.google.com/), set the source language to Kannada, and press the speaker icon to hear native text-to-speech — currently one of the most reliable free audio sources for Kannada.
- Search pronunciations on [Forvo](https://forvo.com), the crowd-sourced pronunciation dictionary — look up individual words like "amma" or "namaskara" under Kannada.
- YouTube search: [kannada alphabet pronunciation](https://www.youtube.com/results?search_query=kannada+alphabet+pronunciation)
- YouTube search: [kannada retroflex vs dental sounds](https://www.youtube.com/results?search_query=kannada+retroflex+vs+dental+sounds)
- For the full script chart as a reference page, see [Omniglot: Kannada](https://www.omniglot.com/writing/kannada.htm).

## Practice

1. Say the 10 vowels out loud in order, then again from memory.
2. Pick 3 word pairs that differ only by dental/retroflex (e.g. practice `ta` vs `Ta`, `na` vs `Na`) and say each pair back to back 5 times.
3. Record yourself saying all 10 example words, then compare against the Google Translate audio.
4. Write out the romanization convention from memory — can you still tell `aa` from `a`, and `T` from `t`?
