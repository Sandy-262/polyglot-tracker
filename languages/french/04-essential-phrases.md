# Lesson 4: Essential Phrases

**Goal:** Handle basic survival situations and ask simple questions.

## Survival phrases

| French | Pronunciation guide | English |
|---|---|---|
| S'il vous plaît | seel voo PLEH | Please (formal/general) |
| Merci (beaucoup) | mehr-SEE (boh-KOO) | Thank you (very much) |
| De rien | duh RYEN | You're welcome |
| Pardon / Excusez-moi | par-DOHN / ex-kuh-zay MWAH | Sorry / Excuse me |
| Oui / Non | WEE / NOHN | Yes / No |
| Je ne comprends pas | zhuh nuh kohm-prahn PAH | I don't understand |
| Parlez-vous anglais ? | par-lay voo ahn-GLEH | Do you speak English? |
| Où sont les toilettes ? | oo sohn lay twah-LET | Where is the bathroom? |
| Combien ça coûte ? | kohm-byen sah KOOT | How much does this cost? |
| Pouvez-vous répéter ? | poo-vay voo ray-pay-TAY | Can you repeat that? |
| Parlez plus lentement, s'il vous plaît | par-lay plu lahnt-MAHN | Please speak more slowly |
| Je ne sais pas | zhuh nuh say PAH | I don't know |
| Au secours ! | oh suh-KOOR | Help! |

## Question words

| French | Pronunciation guide | English |
|---|---|---|
| Qui | KEE | Who |
| Quoi / Qu'est-ce que | KWAH / kess-kuh | What |
| Quand | KAHN | When |
| Où | OO | Where |
| Pourquoi | poor-KWAH | Why |
| Comment | koh-MAHN | How |

Example questions: *Qui est-ce ?* (Who is it?), *Qu'est-ce que c'est ?* (What is this?), *Où est la gare ?* (Where is the train station?), *Pourquoi pas ?* (Why not?).

## Putting it together

> *Pardon, parlez-vous anglais ? Je ne comprends pas bien le français. Pouvez-vous répéter, s'il vous plaît ?*
> (Sorry, do you speak English? I don't understand French well. Can you repeat, please?)

## Practice

1. Say all the survival phrases out loud, 3 times each.
2. Form 3 original questions using qui/quoi/où.
3. Role-play: you're lost and need directions — use "excusez-moi," a question word, and "merci."
4. Record yourself saying the "putting it together" sentence and compare to the Google Translate audio.
