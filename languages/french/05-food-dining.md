# Lesson 5: Food & Dining

**Goal:** Order food, state dietary needs, and handle a café or restaurant visit.

## Restaurant vocabulary

| French | Pronunciation guide | English |
|---|---|---|
| le restaurant | luh res-toh-RAHN | restaurant |
| le menu / la carte | luh muh-NU / lah KART | menu |
| la table | lah TAHBL | table |
| l'addition | lah-dee-see-OHN | the bill |
| le serveur / la serveuse | luh sehr-VUHR / lah sehr-VUHZ | waiter / waitress |
| le petit-déjeuner | luh puh-tee day-zhuh-NAY | breakfast |
| le déjeuner | luh day-zhuh-NAY | lunch |
| le dîner | luh dee-NAY | dinner |

## Ordering phrases

| French | Pronunciation guide | English |
|---|---|---|
| Je voudrais... | zhuh voo-DREH | I would like... |
| Pour moi, ... | poor MWAH | For me, ... |
| Qu'est-ce que vous recommandez ? | kess-kuh voo ruh-koh-mahn-DAY | What do you recommend? |
| L'addition, s'il vous plaît | lah-dee-see-ohn seel voo PLEH | The bill, please |
| C'est délicieux | seh day-lee-SYUH | It's delicious |
| À table ! | ah TAHBL | Let's eat! (said before a meal) |

## Example café dialogue

> **Serveur:** Bonjour ! Qu'est-ce que je vous sers ?
> **Vous:** Bonjour, je voudrais un café et un croissant, s'il vous plaît.
> **Serveur:** Très bien. Autre chose ?
> **Vous:** Non, merci, c'est tout. L'addition, s'il vous plaît.
> **Serveur:** Bien sûr, tout de suite.

## Practice

1. Order a full meal out loud using "Je voudrais..." three times (starter, main, drink).
2. State that you are vegetarian and allergic to nuts.
3. Role-play the café dialogue above, playing both parts.
4. Ask "Qu'est-ce que vous recommandez ?" and improvise a waiter's answer.
